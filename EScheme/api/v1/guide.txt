EScheme API v1 — инструкция для генерации схем

Задача агента
По описанию пользователя верни один JSON-объект формата escheme/v1.
Если пользователь просит файл, сохрани его как circuit.json в UTF-8.
Если он просит код на JavaScript, создай такой же объект и передай его в buildCircuit(spec).
Для запроса «собери схему» выводи сам JSON без комментариев и ограждающих блоков Markdown.
Пользователь вставляет JSON в редактор через «Из кода» → «Построить» или загружает circuit.json через «Открыть».

Редактор: https://cgsgat6.github.io/EScheme/
JSON Schema: https://cgsgat6.github.io/EScheme/api/v1/schema.json
Рабочий пример: https://cgsgat6.github.io/EScheme/api/v1/example.json
JavaScript ES-модуль: https://cgsgat6.github.io/EScheme/api/v1/escheme.mjs

Формат
Обязательные поля верхнего уровня: format, name, parts, wires.
format всегда равен "escheme/v1". name — название схемы.
Каждая запись parts содержит id, type и at. Записи ссылаются друг на друга по id.
id начинается с латинской буквы, далее разрешены латинские буквы, цифры, дефис и подчёркивание. До 64 символов. Регистр важен.
at — координаты центра символа [x, y]. Ось x направлена вправо, y — вниз. Используй шаг 10 и оставляй пространство для надписей.
rotate — необязательный угол по часовой стрелке: 0, 90, 180, 270. Выводы поворачиваются вместе с прибором.
label — обозначение на схеме (по умолчанию id, у узла пусто), name — дополнительная подпись, value — строка с номиналом и единицами.
У провода обязательны from и to, например "R1.a" и "PA1.b". Необязательный via — список промежуточных точек в порядке от from к to.
Для электрического разветвления поставь junction и подведи провода к его выводу a. Простое пересечение линий не образует контакта.
Идентификаторы элементов уникальны. Обе ссылки провода должны указывать на разные существующие выводы. Порядок объявления частей не влияет на соединения.

Каталог встроенных символов
type          прибор                    выводы
battery       батарея                   a, b
ac            источник переменного тока a, b
resistor      резистор                  a, b
rheostat      реостат                   a, b и w (движок)
capacitor     конденсатор               a, b
inductor      катушка                   a, b
switch        ключ                      a, b
ammeter       амперметр                 a, b
voltmeter     вольтметр                 a, b
junction      точка соединения          a

При угле 0 символ двухполюсника занимает 80 × 40, a находится на 40 единиц левее центра, b — на 40 правее.
У батареи a находится со стороны длинной пластины (+). У реостата w расположен на 11 единиц правее и 20 выше центра. У узла a в центре.
На разворотах проводи линии за пределами символов. Для замкнутого контура задай изгибы обратного провода через via.

Пример. «Подключи резистор 100 Ом к батарее 6 В»
{
  "format": "escheme/v1",
  "name": "Цепь с резистором",
  "parts": [
    {"id": "G1", "type": "battery", "at": [80, 160], "rotate": 90, "value": "6 В"},
    {"id": "R1", "type": "resistor", "at": [240, 160], "rotate": 90, "value": "100 Ом"}
  ],
  "wires": [
    {"from": "G1.a", "to": "R1.a"},
    {"from": "R1.b", "to": "G1.b"}
  ]
}

В примере example.json амперметр включён последовательно, вольтметр параллельно резистору. Два узла задают точки разветвления.

Пользовательские символы
Добавь в необязательный массив custom определения из массива custom сохранённого проекта EScheme. У каждого определения нужны key с префиксом custom-, name, положительные width и height, image как data:image/png;base64,... и массив ports. У каждого вывода уникальный id и координаты x,y внутри изображения относительно его верхнего левого угла. В parts укажи type, равный key. Подключайся по фактическому id вывода, например "X1.p1". Определения и изображения будут включены в проект.

Программный API
buildCircuit(spec) принимает объект или JSON-строку и возвращает новый редактируемый проект EScheme. Результат можно записать в .escheme.json. При ошибке функция выбрасывает Error. Сообщение указывает поле, например wires[2].to. Для ошибок синтаксиса JSON возвращается SyntaxError.
catalog() возвращает типы, названия, размеры и локальные координаты выводов встроенных элементов.
format содержит строку "escheme/v1".

Node.js. Скачай escheme.mjs по ссылке выше и положи рядом со скриптом build.mjs и созданным агентом circuit.json. Запусти node build.mjs. Содержимое build.mjs:

import { readFile, writeFile } from 'node:fs/promises';
import { buildCircuit } from './escheme.mjs';
const spec = await readFile('circuit.json', 'utf8');
await writeFile('circuit.escheme.json', JSON.stringify(buildCircuit(spec), null, 2));

В браузере можно импортировать тот же модуль по HTTPS. На открытой странице редактора доступен window.EScheme:
EScheme.loadCircuit(spec) — проверить код и показать его вместо текущей схемы; предыдущая схема доступна через «Отменить».
EScheme.getProject() — получить независимую копию текущего проекта.
EScheme.toSVG() — получить строку SVG текущей схемы.
EScheme.buildCircuit(spec), EScheme.catalog() и EScheme.format совпадают с экспортами модуля.

Спецификация описывает электрические соединения и геометрию чертежа. Выбор схемы и расположения приборов по текстовому запросу выполняет агент.
